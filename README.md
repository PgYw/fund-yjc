## 好用的功能，一个个说

### 看盘

- **大盘云图**：把整个 A 股浓缩成一张可交互的矩形树图，**面积 = 流通市值、颜色 = 涨跌幅**。覆盖约 **5400 只个股、31 个一级行业板块**，支持行业 → 子板块 → 个股三级下钻，市场范围和涨跌周期随意切换
- **大盘弹幕**：直接在上证分时图上发弹幕、看历史，和基友一起吐槽今天的行情
- **市场异动时间轴**：盘中哪些板块、哪些个股突然跳变，按时间轴一条条列出来，点进去就是详情
- **放量 / 缩量转折标签**：近 5 分钟成交量偏离 ±12% 且持续 4 分钟以上，自动打标提醒
- **板块资金流向图、主题与板块发现、期货走势**，一个页面看完
- 图表和数据是**实时推送**的，不用手动刷新

### 算账

- **当日预估收益**：可以按金额看，也可以按收益率看；A 股 / 港股用已公布的实际值，未公布的用预估补上，美股单独列，货基不计入——口径写在界面上
- **分钟级收益曲线**：交易时段**每分钟一个点**，图上还会标出当天最高、最低、收盘后"更新后"的金额，以及你切换估值源的那一刻
- **收益日历**：日 / 周 / 月 / 年四种粒度，点开任意一天就能看当天每只基金赚了多少
- **收益分享卡片**：可自定义要不要显示上证 / 恒科走势、要不要显示收益金额、要不要算"跑赢多少"、推荐哪几只持仓，最多选 3 只
- **交易记录可纠正**：撤销、改金额、改手续费、修正转换，记错了随时改

### 持仓

- **23 个自定义列**自由组合，配置跟着账号走，换设备也在
- **组合管理**：多组合分类、拖拽调整顺序、一键基金转换
- **定投两种玩法**：定期定投（每周 / 每月指定日期），或者**涨跌定投**——单日涨跌幅达到你设的阈值（0~20%）才买入。可暂停、可恢复、可终止，能看到"已触发几次、累计投入多少"
- **上传持仓截图，AI 自动识别金额**：从别的平台搬过来，拖一张图进去，金额自动填好

### 挑基

- **净值排行榜**：涨跌榜、**机会榜**（连跌 ≥3 天）、**风险榜**（连涨 ≥3 天），可按技术指标、涨跌幅、连续涨跌、关联主题组合筛选
- **估值排行榜**：按盘中估值涨跌幅排序
- **智能标签**：止跌、止涨、多头排列、MACD 金叉、RSI 超卖、近一年低位……每个标签都配了大白话解释
- **基金详情 5 个 Tab**：当日走势、历史净值、基金信息、相关主题、同比增长
- **历史净值区间分析**：在净值曲线上一框，自动算出区间涨幅、年化、最大回撤
- **基金对比**：和沪深 300、同类基金摆在一起看
- **全局搜索**：跨基金、股票、板块、资讯，一搜就到

### 估值

- **双估值源一键切换**：源 1 是第三方实时估值，源 2 是自研估值，切换零等待，历史曲线里还会标出你切换的时间点
